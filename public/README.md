# Public Assets (`public/`)

Denne mappen inneholder statiske filer og bilder som serveres direkte fra rot-URL-en (`https://krsvr.no/`):

- `logo.svg` / `icon.svg`: Vektorlogo og favicon for nettsiden.
- `krsvrarena_logo_sort.png`: PNG-logo for lys bakgrunn (brukes i alle e-postmaler / React Email og Schema.org JSON-LD).
- `krsvrarena_logo_hvit.png`: PNG-logo for mørk bakgrunn.
- `images/`: Bilder til forsiden, opplevelser og arrangementssider (`/arrangementer/*`).
